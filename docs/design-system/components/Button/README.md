Dispara uma ação dentro de uma tela.

Use `primary` para a ação principal da área, no máximo uma por área. Use `secondary` para ações alternativas, como Cancelar. Use `ghost` dentro de tabelas e cabeçalhos. Use `danger` apenas para ações destrutivas, sempre com confirmação em modal.

O consumidor fornece o rótulo (verbo mais objeto), a variante e o estado de carregamento. Durante o carregamento, mantenha o rótulo e desabilite o botão para evitar envio duplo.

Alturas: `sm` 32px, `md` 40px, `lg` 48px. Estados: default, hover, foco (anel de 2px em `color-brand-500`), pressionado, desabilitado e carregando.
