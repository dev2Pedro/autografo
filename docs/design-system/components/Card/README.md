Agrupa informações relacionadas em uma superfície com título.

Use para agrupar dados de uma entidade ou de uma seção. Cards em repouso usam borda `color-neutral-300`, fundo `color-neutral-0` e `shadow-sm`. Use a variante interativa somente quando o card inteiro for clicável, com `<a>` ou `<button>` real, e com elevação `shadow-md` no hover.

Cabeçalho traz o título e as ações. Corpo traz o conteúdo. Rodapé é opcional.

O consumidor fornece o título, o conteúdo e, se for interativo, o destino.
