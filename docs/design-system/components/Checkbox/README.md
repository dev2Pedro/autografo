Seleção de uma opção independente, como aceite ou item de uma lista.

Use para escolhas que o usuário confirma junto com o envio do formulário. Sempre tenha um rótulo visível ao lado. Para seleção de vários itens de uma lista, use checkboxes agrupados sob uma legenda.

Marcado usa `color-brand-700` com marca branca. Desmarcado usa borda `color-neutral-500`. O foco segue o padrão de anel de 2px.

O consumidor fornece o rótulo e o estado.
