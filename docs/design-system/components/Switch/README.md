Ativa ou desativa uma configuração que tem efeito imediato.

Use quando a mudança de estado vale na hora, sem envio de formulário. Não use para aceite ou seleção que depende de envio, pois nesse caso use `Checkbox`. Sempre tenha rótulo visível e texto indicando o estado atual, como "Ativado" ou "Desativado".

Trilho ligado usa `color-brand-700`. Trilho desligado usa `color-neutral-500`, que atende 3:1 sobre a superfície.

O consumidor fornece o rótulo e o estado.
