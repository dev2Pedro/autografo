Informa uma falha ao carregar uma página ou seção e oferece nova tentativa.

Use quando uma requisição falha e não há dados para mostrar. Estrutura: mensagem clara do que falhou, ação "Tentar novamente" e, quando houver, código de referência. Não exponha detalhes técnicos internos.

Para uma falha de ação pontual, prefira `Alert` ou `Toast`.

O consumidor fornece a mensagem, a ação e o código de referência, se houver.
