Lista as versões de um desenho, da mais recente para a mais antiga.

Use na seção Versões do detalhe do transformador e no histórico do desenho. Colunas: versão (número em `value-sm`), data, status e ação "Visualizar". A versão atual recebe o badge "Atual" com fundo `color-brand-100` e texto `color-brand-900`.

Comparação entre versões não faz parte deste escopo.

O consumidor fornece as versões, a versão atual e a ação de visualização.
