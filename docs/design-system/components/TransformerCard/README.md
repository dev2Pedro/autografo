Resume um transformador no dashboard, com nome, dados elétricos principais e status do último desenho.

Use somente no dashboard, na grade de projetos. O nome ocupa o topo. A linha de dados traz potência, tensões e fases, em `value-sm`, com unidades. O badge de status aparece quando há desenho. A ação "Abrir" leva aos detalhes.

O consumidor fornece o nome, os dados elétricos, o status do último desenho e o destino.
