Confirma uma ação assíncrona concluída sem interromper o trabalho.

Use para sucesso, como "Transformador salvo", e para erro não bloqueante. Fica no canto inferior direito em desktop e na parte inferior em mobile. Sucesso some em 5 segundos. Erro permanece até o fechamento manual.

Sucesso anuncia com `role="status"`. Erro anuncia com `role="alert"`. Toda notificação traz ícone e texto.

O consumidor fornece a mensagem e o tipo.
