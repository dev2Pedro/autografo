Pede confirmação ou exibe um formulário curto sem sair da tela.

Use para confirmar ações destrutivas, como excluir um transformador, e para formulários de uma ou duas linhas. Não use para conteúdo longo: nesse caso, use uma tela própria.

Título descreve a ação. A ação primária fica à direita e a secundária à esquerda. Em ação destrutiva, a primária é `danger`. Fundo `color-neutral-0`, raio `radius-lg` e `shadow-md`.

Enquanto aberto, o foco fica preso dentro do modal. Esc fecha, exceto durante operação em andamento. Ao fechar, o foco volta ao elemento que abriu o modal.

O consumidor fornece o título, o conteúdo e as ações.
