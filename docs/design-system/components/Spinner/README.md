Indica uma ação pontual em andamento, como gerar um desenho ou salvar um formulário.

Use dentro de botões, no lugar do ícone, mantendo o rótulo visível. Para áreas inteiras que carregam, use `Skeleton`. Anel em `color-brand-700` sobre `color-neutral-0`, com `aria-label` "Carregando".

O consumidor fornece o tamanho (16px ou 20px) e o texto de apoio, se houver.
