Exibe o desenho SVG gerado de uma versão, com ferramentas de visualização e informações da versão.

Use somente na tela de visualização do desenho. A folha usa `drawing-paper` em qualquer tema. Linhas usam `drawing-line`, linhas ocultas são tracejadas em `drawing-hidden`, cotas usam `drawing-dimension` e textos usam `drawing-text`.

Barra de ferramentas: regenerar, zoom (+, −, ajustar), alternar grade e exportar PDF (desabilitado até a fase de PDF, com dica explicando). Rodapé: versão, data de geração e parâmetros resumidos. O aviso "Desenho hipotético e demonstrativo. Não utilizar para fins de engenharia." é obrigatório.

O zoom altera a escala, não o conteúdo. Quando o zoom excede o contêiner, a área rola. Regenerar mantém a versão anterior visível sob uma sobreposição semitransparente.

O consumidor fornece o SVG, a versão, a data e os parâmetros.
