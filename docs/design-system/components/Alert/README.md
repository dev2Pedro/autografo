Traz uma mensagem persistente dentro da página, enquanto a condição existir.

Use para situações que o usuário precisa ler antes de continuar: erro de carregamento de uma seção, aviso de ambiente demonstrativo ou informação sobre um cálculo. Variantes: `info`, `success`, `warning` e `error`, cada uma com fundo `-100` e texto `-700`.

Sempre traz ícone e texto. Não use alerta para validação de campo: nesse caso, use a mensagem do `Field`.

O consumidor fornece a variante e a mensagem.
