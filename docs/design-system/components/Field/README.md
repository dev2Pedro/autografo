Agrupa rótulo, controle, texto de ajuda e mensagem de erro de um campo de formulário.

Use em todo campo de formulário, sem exceção, para garantir o mesmo alinhamento e a mesma associação de rótulo. O rótulo fica sempre visível acima do controle. O texto de ajuda aparece abaixo do rótulo e a mensagem de erro, abaixo do controle, com ícone e texto.

O consumidor fornece o identificador do campo, o rótulo, o controle e, quando houver, o texto de ajuda e o erro.
