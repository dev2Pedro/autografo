# Dados técnicos

| Grandeza | Formato | Exemplo |
| --- | --- | --- |
| Potência | inteiro com unidade | 500 kVA |
| Tensão | milhar com ponto e unidade | 13.800 V |
| Frequência | inteiro com unidade | 60 Hz |
| Fases | inteiro | 3 |
| Dimensões | inteiro com unidade | 900 mm |
| Quantidade | inteiro | 4 |
| Data e hora | dd/mm/aaaa HH:mm | 21/10/2026 14:35 |

- Separador decimal é vírgula. Separador de milhar é ponto.
- A unidade aparece sempre: no valor ou no cabeçalho da coluna, como "Potência (kVA)".
- Valores numéricos alinham à direita em tabelas.
- Valor ausente aparece como travessão (—).
